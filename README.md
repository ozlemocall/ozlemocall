## Projelerimden Bazıları

- **Virtualized Corporate Network & Security Infrastructure – Staj Projesi:**  
  VMware Workstation üzerinde FortiGate, Open vSwitch, Windows Server ve Ubuntu Server kullanılarak oluşturulan sanal kurumsal ağ altyapısı. VLAN segmentasyonu, firewall politikaları, Active Directory, DNS/DHCP, SFTP ve mail servisleri ile güvenlik testleri üzerine çalışıldı.

- **Kurumsal Web Uygulaması – Staj Projesi:**  
  Java ve Spring Boot kullanılarak geliştirilen ticari bir web uygulamasının geliştirme sürecinde görev aldım. İş takibi, müşteri ve personel yönetimi, rol ilişkileri, durum ve teslim süreçleri gibi işlevlerin geliştirilmesi üzerinde çalıştım. Projenin ticari niteliği nedeniyle kaynak kodu ve gerçek uygulama ekranları paylaşılmamaktadır.

- **SolarMod Mobil Uygulaması:**  
  Güneş enerjisi sistemlerinin üretim, batarya ve panel durumlarının takip edilmesini sağlayan Flutter tabanlı IoT mobil uygulaması.

- **Kütüphane Otomasyon Sistemi:**  
  C# ve SQL kullanılarak geliştirilen, kullanıcı yönetimi ve veritabanı işlemlerini içeren web tabanlı sistem.

- **E-Ticaret Uygulaması:**  
  C# ve SQL kullanılarak geliştirilen; ürün listeleme, kategori, favoriler ve sepet işlemlerini içeren uygulama.

 - **Decision Tree Tabanlı Enerji Yük Analizi:**
   Python ve Scikit-learn kullanılarak enerji yük durumlarını sınıflandıran karar ağacı tabanlı model geliştirildi; veri ön işleme, model değerlendirme ve görselleştirme uygulandı.
